# D：公共能力起始说明

依据：[任务书](../../../../Pj-任务书.pdf)第 1 页。目前先列以下四项已明确的公共能力，不是最终完整需求；收集各模块的需求后，可以细化或提出补充能力，标为提案并由组内确认。

| 编号 | 能力 | 简单说明 |
| --- | --- | --- |
| D-F01 | RBAC 身份与权限 | 提供用户身份，以及用户角色和权限的公共能力 |
| D-F02 | 空间与座位主数据 | 提供共同使用的空间、座位基础资料 |
| D-F03 | 通知服务 | 为业务模块发送通知 |
| D-F04 | 操作审计 | 记录业务操作，供追溯 |

**这是功能范围说明，不是已经实现的服务，也不是已确定的接口。**

现在 M1、M2、M3 先在自己的功能下面写：“我需要 D 提供什么信息或操作、我会给 D 什么、希望拿到什么结果。”不直接修改这份说明。

收齐需求后，再统一整理 D 的具体功能、数据和接口，并确认由谁负责。当前不提前列设计问题或预设技术方案。

D 提供公共能力；预约、审批、维修的业务处理仍由相应模块负责。模块之间有直接配合的需求，也写在各自功能下。

本轮填法见 [R1 README](../README.md)。
