## 本版采用的开发起点

- D维护同一份身份、权限、教室和座位，提供通知与审计；业务配置分别由M1/M2/M3/D保存。
- M1汇总座位可用性，M2最终审批后占用，M3开始维修下架、验收通过解除；每次只影响自己的来源。
- 重复、旧版本和解除先到按M1-S10/S11处理，原请求结果与当前限制分别说明。
- M1提供统一配置入口；M2、M3必要待办和详情不依赖额外查询页面。
- 维修下架时原个人预约取消为CANCELLED_MAINTENANCE且不记违约；其他来源限制保留。规则、状态和通知目录已同步到相关文档。
- Python、Web、账号密码、邮件、初始审批与超时数值、测试权限按开发指导v1，不由各agent私选。

这些是组长组织的首版开发方案，**没有虚构成员批准或实现完成**。集成链路来自任务书示例，维修取消与具体参数是本版选择，不能写成课程原文。补充功能保留编号，未获后续授权不加入本版。
